# E-Commerce Sales & Operations Dashboard — Excel

## Project Overview
An interactive Microsoft Excel dashboard built to analyze e-commerce sales performance, profitability, order trends, and product returns.

## Business Objectives
- Monitor overall revenue and order performance.
- Analyze average order value (AOV) and units sold.
- Evaluate gross profit and gross margin.
- Track product returns and return rates.
- Explore business performance using interactive filters.

## Tools & Skills
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas and lookup functions
- Slicers and interactive filtering
- KPI cards and dashboard design
- Data analysis and business reporting

## Key Performance Indicators
- Total Revenue
- Total Orders
- Average Order Value (AOV)
- Units Sold
- Total Returns
- Return Rate
- Gross Profit
- Gross Margin

## Dashboard Features
- KPI cards for high-level performance monitoring
- Interactive slicers for filtering dashboard results
- Charts for sales and operational analysis
- PivotTable-based reporting

## Files Included
- Excel workbook containing the dashboard, source data, and analysis.
- Dashboard screenshot.

## How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Use the available slicers to explore performance across supported dimensions.
4. Clear the slicers to return to the overall view.

## Project Purpose
Created as a portfolio project to demonstrate practical Excel skills relevant to entry-level MIS Executive, MIS Analyst, and Data Analyst roles.
